# 配置文件接口

启用 `ControlPlaneToken` 后，客户端拉取和直接 API 调用使用 `Authorization: Bearer <Token>`。控制台先通过 Token 建立浏览器会话，然后从同源 `/public/api/` 路径访问管理接口。鉴权失败返回 `401`。[部署说明](../project/部署与可观测性.md#控制面鉴权)

管理页与客户端共用 `/api/config-files` 前缀。成功结果位于响应的 `data` 字段。

| 方法与路径                                                      | 输入                                                          | 结果                                                                 |
| --------------------------------------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------- |
| `POST /api/config-files`                                        | 正文含 `name`、`content`，可附 `id`、`format`、`description`  | 保存草稿，返回可用于后续发布的草稿记录                               |
| `PUT /api/config-files/:id`                                     | 兼容部分更新，可传 `name`、`content`、`format`、`description` | 编辑已发布快照时返回同名草稿的 ID。版本、发布时间和 MD5 由服务端维护 |
| `POST /api/config-files/:id/publish`                            | 保存接口返回的 ID                                             | 校验草稿并发布，返回已发布快照                                       |
| `GET /api/config-files/page`                                    | `pageNum`、`pageSize`，可选 `search`、`format`、`published`   | 返回按名称聚合的分页 `list`                                          |
| `GET /api/config-files/latest`、`GET /api/config-files/history` | `name`                                                        | 返回最近发布记录或该名称的版本列表                                   |
| `GET /api/config-files/client/pull`                             | 可选 `serviceName`、逗号分隔的 `names`                        | 返回所选快照 `configs` 和合并结果 `mergedConfig`                     |
| `DELETE /api/config-files`                                      | 请求体为 ID 数组                                              | 批量移除对应记录                                                     |

草稿正文语法错误或根节点类型错误时，发布返回 HTTP 400。指定记录不存在时返回 404，保存与发布发生并发写冲突时返回 409。历史数据无有效发布版本时，拉取返回 422。具体规则见[配置发布与客户端协作](./配置发布与客户端协作.md)。
