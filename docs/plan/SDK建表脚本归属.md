## 验证结果

三仓仅 NestCloud 保留一份建表 SQL。SDK 包内的 SQL 文件数为 0。全新 PostgreSQL 16 业务库连续两次成功执行规范脚本。SDK 通过 4 项数据库幂等专项，中间件通过 2 项真实跨实例 HTTP 重试专项。

使用独立数据库、pgvector 和 Redis 启动了 NestCloud、SolaCloud 的三个后端以及 Vite 前端。通过 NestCloud 发布配置并验证了三个后端的实际注册地址；前端代理成功查询系统会话、文件列表和知识库列表。真实浏览器登录、权限查询、页面刷新和登出均通过。RAG 首次按随仓 SQL 启动时缺少业务表，补建过程和影响见 [RAG 新库启动记录](../../../SolaCloud/docs/experience/common/RAG新库启动缺少DeepAgents业务表.md)。
