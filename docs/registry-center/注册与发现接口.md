# 注册与发现接口

启用 `ControlPlaneToken` 后，业务客户端调用本页接口时使用 `Authorization: Bearer <Token>`。控制台使用已验证的浏览器会话从同源 `/public/api/` 访问管理接口。鉴权失败返回 `401`。[部署说明](../project/部署与可观测性.md#控制面鉴权)

## 注册实例

`POST /api/registry/register` 接收 JSON 对象。

| 字段                | 约束                        | 含义                                     |
| ------------------- | --------------------------- | ---------------------------------------- |
| `id`、`name`        | 必填，非空字符串            | 实例 ID 与服务名                         |
| `baseUrl`           | 可选，完整 HTTP(S) URL      | 对外服务地址，含路径前缀，可使用显式端口 |
| `host`、`port`      | 省略 `baseUrl` 时两者均必填 | 实例主机和端口，端口范围为 1 至 65535    |
| `group`、`metadata` | 可选                        | 实例分组及附加信息                       |

例如，`{"id":"middleware-1","name":"middleware-service","baseUrl":"https://middleware.example.com/api"}` 会保存完整地址，并补齐 `host=middleware.example.com`、`port=443`。若同时提供独立的 `host` 和 `port`，会保留这两个值供旧客户端读取。

实例也可发送 `{"id":"middleware-1","name":"middleware-service","host":"10.0.0.7","port":3300}`。注册中心生成心跳时间，并兼容丢弃旧客户端上报的 `heartbeatInterval`。基础地址只接受协议、主机、可选端口和路径，参数校验失败返回 HTTP 400。

## 心跳续约

`POST /api/registry/heartbeat/{id}` 根据实例 ID 续约，由注册中心记录接收时间。响应的 `data.success` 表示是否续约成功，实例不存在时返回 `false`。

## 读取实例

`GET /api/registry/discover/{serviceName}` 按服务名返回实例，可通过 `group` 过滤。`GET /api/registry/all` 按服务名返回实例清单。两者均沿用原有响应结构，包含注册时传入的 `baseUrl`。新消费端优先使用该字段，旧记录继续通过 `http://host:port` 访问。

两个接口均过滤已手动摘除的实例。SDK 已缓存的实例列表在下一次同步成功后更新。

## 注册中心总览

`GET /api/registry/overview` 的 `heartbeat` 字段提供当前登记实例的心跳统计。最近一次续约距离当前时间未超过租约超时阈值的实例计入 `healthyInstanceCount`，超过阈值且尚未清理的实例计入 `timedOutInstanceCount`。初次注册会初始化心跳时间，手动摘除期间实例仍按其租约参与心跳统计。租约清理后移出统计。原有 `metrics` 字段继续提供累计请求次数。

## 服务健康状态

`GET /api/registry/services` 在 `instances[].health` 返回每个实例的心跳状态。手动摘除的实例仍在明细中显示实际心跳状态。

| `health` | 控制台显示 | 规则 |
| --- | --- | --- |
| `healthy` | 绿色，健康 | 连续收到三次成功心跳 |
| `warning` | 黄色，预警 | 连续漏跳一至两次，或注册、恢复后尚未连续成功三次 |
| `critical` | 红色，连续失败 | 连续漏跳三次或以上 |

注册中心统一使用 30 秒心跳间隔和 1 秒容差。距上次续约达到 31 秒时记一次漏跳，达到 91 秒时记三次漏跳。漏跳后的下一次成功从一次重新计数。超过 180 秒未续约的实例由清理任务移除。

服务总览的 `healthScore` 是接收流量的实例健康均分。绿、黄、红三种实例状态分别计 100、50、0 分，均分四舍五入为整数。服务 `health` 在 75–100 分时为 `healthy`（绿），25–74 分为 `warning`（黄），0–24 分为 `critical`（红）。没有接收流量的实例时为 `unavailable`（灰），分数为 `null`。所选分组限制参与计算的实例范围。

## 手动摘除与恢复

`POST /api/registry/availability` 接收 `{"id":"middleware-1","state":"disabled"}`，将实例从服务发现中摘除。将 `state` 改为 `enabled` 恢复服务发现。更新成功的响应为 `data: true`，实例不存在时返回 HTTP 404。控制台在实例明细中用「接收流量」开关执行这两个操作。

摘除保留实例租约和心跳。相同 ID 的注册更新会保留租约上的摘除状态。管理接口 `GET /api/registry/services` 仍返回该实例，并带有 `disabled: true`，同时在线实例数将其排除。正常退出注销或超过心跳超时后，租约随实例删除，下次注册默认接收流量。
